# Xiaomi Mi Box 4 (MIBOX4, ro.product.device oneday, Amlogic), Android TV 9, firmware PI.3933
# Same hardware as examples/xiaomi-mibox4 but the older Android 9 firmware, with a different set of
# preloads (Alphonso ad tracking, no com.mi.bluetooth / xiaomi.statistic / Mi TV+).
# A streaming box, not a TV: no HDMI-in or tuner, so the launcher hides its Inputs pill.
#
# Apply:   TV_HOST=<box ip> tools/disable.sh examples/xiaomi-mibox4-android9/debloat.txt
# Undo:    TV_HOST=<box ip> tools/restore.sh examples/xiaomi-mibox4-android9/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
